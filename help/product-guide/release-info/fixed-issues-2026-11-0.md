# 2026.11.0 릴리스의 문제가 해결되었습니다.

이 문서에서는 Adobe Experience Manager Guides as a Cloud Service의 2026.11.0 릴리스의 다양한 영역에서 수정된 버그를 다룹니다.

새로운 기능 및 향상된 기능에 대한 자세한 내용은 [2026.11.0 릴리스의 새로운 기능](./whats-new-2026-11-0.md)을 참조하세요.

[2026.11.0 릴리스의 업그레이드 지침](./upgrade-instructions-2026-11-0.md)에 대해 알아봅니다.

## 편집기 2.0

- 편집기에서 탐색 표시를 사용하여 표 행을 선택하고 상황에 맞는 메뉴에서 **삭제** 옵션을 선택하면 전체 행을 삭제하는 대신 셀 내용만 제거됩니다. (GUIDES-56759)
- Microsoft Word에서 표를 붙여넣으면 머리글 행 셀이 만들어지지만 해당 내용은 손실됩니다. (GUIDES-49847)
- 편집기 2.0으로 이동하기 전에 만든 파일에서 추적된 변경 내용이 **변경 내용 추적** 패널에 표시되지 않습니다. (GUIDES-44777)
- Ctrl+V를 사용하여 Microsoft Word 또는 유사한 텍스트 편집기에서 `codeblock` 요소에 코드를 붙여넣으면 줄바꿈과 선행 공백이 손실되고 코드가 한 줄로 병합됩니다. (GUIDES-33247)

## 작성

- 통합 쉘이 활성화되면 Adobe Experience Manager Guides 헤더가 편집기 및 맵 콘솔에도 표시됩니다. (GUIDES-56812)
- Assets UI에서 **소스 보기**, **주제 편집** 및 **UUID 링크 공유**&#x200B;와 같은 DITA 관련 작업이 DITA가 아닌 자산에 대해 표시됩니다. 또한 **UUID 링크 공유**&#x200B;는 UUID가 없는 자산에 대해 잘못된 링크를 생성합니다. (GUIDES-47043)
- 제목 구성표 패널에서 표시 제목은 `navtitle` 특성에서만 선택됩니다. `navtitle` 요소는 둘 다 있는 경우에도 무시됩니다. (GUIDES-37722)
- 저장소 패널의 **제목 보기**&#x200B;에서 긴 이름을 가진 파일의 줄임표는 처음에 표시되지 않습니다. 이러한 파일을 마우스 오른쪽 버튼으로 클릭하면 줄임표와 컨텍스트 메뉴가 파일의 오른쪽 끝에 나타나며, 때로는 부분적으로 화면이 표시되지 않습니다. (GUIDES-37118)
- 조건 패널에서 조건은 레이블이 아니라 값을 기준으로 알파벳순으로 정렬됩니다. (GUIDES-14593)
- 출력 템플릿에서 layout.css와 같은 스타일시트를 열 때 스타일 패널에 **새 스타일**(+) 단추가 표시되지 않습니다. (GUIDES-49448)

## 자산 관리

- **기존 파일 덮어쓰기** 옵션을 사용하여 수정된 파일을 업로드할 때 기존 파일에 안내서 UUID가 없고 **사후 처리를 위해 무시된 경로**&#x200B;에 나열된 폴더에 저장된 경우 업로드가 완료된 것으로 표시됩니다. 그러나 기존 파일을 덮어쓰지 않으며 새 버전이 만들어지지 않습니다. (GUIDES-55866)
- 북맵에서 `booktitle` 요소에 `booklibrary` 및 `mainbooktitle`과(와) 같은 여러 하위 요소가 포함되어 있으면 `dc:title` 메타데이터의 값 사이에 추가 공백이 추가됩니다. (GUIDES-28877)

## 게시

- 맵 콘솔에서 한 맵에 대한 출력이 생성되면 다른 맵을 열 때 **생성** 단추가 비활성화됩니다. 브라우저를 새로 고치면 버튼이 다시 활성화됩니다. (GUIDES-54591)
- 목차를 만드는 동안 구성 요소 매핑을 사용하여 AEM 사이트에 특정 맵을 게시하면 오류가 발생하여 실패합니다. (GUIDES-53807)
- 맵에 `navtitle` 특성이 있고 `href` 특성이 없는 `topicref` 요소가 있으면 구성 요소 매핑을 사용하여 AEM 사이트에 맵을 게시하지 못합니다. 요소가 제거된 후에도 생성된 사이트 노드가 삭제될 때까지 후속 시도가 실패합니다. (GUIDES-53707)
- 구성 요소 매핑이 있는 AEM 사이트 출력에서 레벨 2~6의 Markdown 제목은 레벨 1 제목으로 렌더링됩니다. (GUIDES-51134)
- 구성 요소 매핑이 있는 AEM 사이트 출력의 경우 작성자, 키워드 및 리소스 ID와 같은 프롤로그 메타데이터가 게시된 출력의 페이지 본문에 표시됩니다. (GUIDES-44087)
- 주제가 ServiceNow에 게시되면 문서 본문에 주제에 대한 간략한 설명과 프롤로그가 포함됩니다. (GUIDES-47868)
- ServiceNow에 이미 게시된 주제가 다시 게시되면 기존 문서를 덮어쓰는 대신 초안 상태에서 새 문서가 만들어집니다. (GUIDES-37872)
- 조건 사전 설정에서 Salesforce에 게시하는 동안 주제 참조를 제외하면 나머지 주제가 성공적으로 게시되었더라도 출력 생성에 실패로 보고됩니다. (GUIDES-37807)
- 게이트웨이 시간 초과 오류가 발생하여 Salesforce에 큰 맵을 게시하지 못합니다. (GUIDES-33722)
- 요청에 25개 이상의 작업이 포함된 경우 제한 초과 오류와 함께 Salesforce에 맵을 게시하지 못합니다. (GUIDES-33721)
- 맵 대시보드(이전)에서 기존 조건 사전 설정에서 **모두 추가**&#x200B;는 사전 설정을 만든 후 추가되거나 변경된 조건 값을 선택하지 않습니다. (GUIDES-45940)
- 경고가 포함된 **출력 기록** 페이지의 로그가 녹색 아이콘으로 표시되어 경고가 있음을 나타내지 않습니다. (GUIDES-27000)
- 맵 콘텐츠에서 용어집 항목을 참조하는 용어가 없는 경우 용어집은 출력에 포함되지 않습니다. (GUIDES-52964)
- 부록에서 참조되는 하위 맵의 주제는 부록 콘텐츠 대신 챕터로 렌더링됩니다. (GUIDES-52775)
- 출력 언어가 중국어(간체)로 설정되면 일부 간체 한자가 일본어 글꼴로 렌더링됩니다. (GUIDES-48094)
- 인덱스 항목의 `keyword`, `ph` 및 `sup`과(와) 같은 자식 요소의 텍스트가 손실됩니다. 따라서 일부 색인 레이블이 불완전하거나 비어 있습니다. (GUIDES-40902)
- 인라인 `option` 요소 주위의 공백은 유지되지 않으므로 인접한 텍스트가 함께 결합됩니다. (GUIDES-40900)

## 번역

- 번역 페이지에서 **제목**&#x200B;을 기준으로 검색 및 정렬하면 열에 표시되는 제목 대신 지역화된 메타데이터 값을 사용합니다. (GUIDES-45396)

## 검토

- **검토자** 페이지에서 검토 작업을 만들거나 편집하는 동안 행을 선택하지 않은 경우에도 기본적으로 **선택 지우기**, **검토자 추가**, **검토자 제거** 및 **검토자 다시 할당** 단추가 활성화됩니다. (GUIDES-35125)
- AEM 받은 편지함에서는 작업 할당, 받은 피드백, 언급, 기한 또는 지연 미리 알림과 같은 검토 작업과 관련된 알림이 프로젝트 이름 없이 표시됩니다. (GUIDES-10912)
- 검토 작업에 있는 주제의 나란한 보기에서 취소선으로 표시된 콘텐츠는 두 보기에서 서로 다른 서식으로 표시됩니다. (GUIDES-56079)

## 학습 콘텐츠

- 일반적으로 300MB~600MB의 대규모 과정에 대한 SCORM 출력을 생성하는 데 30분 이상 걸리며 로그에 오류 세부 정보 없이 실패합니다. (GUIDES-56101)
- Experience Manager Guides에서 SCORM 출력의 완료 기준을 설정할 수 없습니다. (GUIDES-55520)
- AVIF 형식의 이미지는 편집기에 표시되지만 게시된 출력에서는 누락됩니다. (GUIDES-55515)
- 게시된 출력의 앵커 태그에서 `href` 특성이 제거되므로 링크를 클릭할 수 없습니다. (GUIDES-55514)

## Platform

- 사용자가 폴더 프로필에서 관리자 사용자로 할당되었지만 관리자 그룹의 구성원이 아닌 경우 다른 관리자 사용자를 추가할 수 없습니다. 성공 메시지가 표시되지만 페이지를 새로 고치면 새로 추가된 사용자가 사라집니다. (GUIDES-50144)

## 알려진 문제

Adobe은 2026.11.0 릴리스에 대해 다음과 같은 알려진 문제를 확인했습니다.

## 작성

- 종속 항목이나 하위 맵이 들어 있는 템플릿에서 맵을 만들 때, 특히 서버의 부하가 높을 때 오류가 발생하여 맵 만들기가 간헐적으로 실패할 수 있습니다. (GUIDES-58715)

### 편집기 2.0

- **탐색 제목 특성 새로 고침** 옵션은 DITA 맵의 기존 `topicref` 요소에 `@navtitle` 특성을 추가하지 않습니다. (GUIDES-54348)

**변경 내용 추적**

**변경 내용 추적**&#x200B;이 켜져 있는 경우:

- 동일한 사용자에 의해 중첩된 삭제된 항목은 삭제된 콘텐츠가 포함된 요소의 이름을 바꾸거나 서식을 지정할 때 항상 단일 항목으로 병합되지 않습니다. (GUIDES-58429)
- 다른 사용자가 중첩된 삭제를 수행하면 **변경 내용 추적** 패널에 상위 요소에 대한 불완전한 내용이 표시되는 경우가 있습니다. (GUIDES-58428)
- 다른 사용자가 삽입한 내용 내에서 콘텐츠를 삭제할 때 왼쪽에는 빨간색 글자 마커가 표시되지 않습니다. (GUIDES-58418)

### 게시

- 기본 PDF 출력에서는 색인 항목에 위 첨자와 아래 첨자 서식이 유지되지 않습니다. (GUIDES-58349)
- 동일한 전역 사전 설정을 사용하여 서로 다른 맵에 대한 출력을 생성하는 경우 이전 맵의 주제 선택이 새 맵의 출력에 영향을 줄 수 있습니다. (GUIDES-58346)
- 책 맵에 유효한 `href`이(가) 있는 챕터와 중첩된 주제 참조가 포함된 경우 AEM Sites에 맵을 게시하면 빈 페이지가 표시됩니다. (GUIDES-58266)
- 변경 내용이 저장되지 않은 사전 설정에서 **출력 기록** 탭으로 이동하면 **저장** 및 **출력 생성** 단추가 계속 표시됩니다. (GUIDES-57989)
- 게시 후 워크플로우가 사전 설정에 대해 구성된 경우 **출력 기록**&#x200B;에 표시되는 게시 기간에는 워크플로우에 걸리는 시간이 포함되지 않습니다. (GUIDES-57856)
- **출력 기록** 페이지에서 기본 PDF 출력 생성을 취소할 수 없습니다. (GUIDES-57821)

### 검토

- 2026.08.0 또는 2026.09.0 릴리스에서 만든 검토 작업을 열면 애플리케이션 오류가 발생할 수 있습니다. (GUIDES-56583) <br>**해결 방법:** 2026.11.0 릴리스로 업그레이드하기 전에 이러한 릴리스에서 만든 모든 검토 작업을 완료하거나 닫습니다.
