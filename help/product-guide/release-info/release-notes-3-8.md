# 릴리스 정보 | Adobe Experience Manager Guides 3.8

**면책조항**:

*Adobe Experience Manager Guides*&#x200B;은(는) 이전에 *Adobe Experience Manager용 XML Documentation* 브랜드로 지정되었습니다. 설명서 내의 특정 참조는 이전 브랜딩을 계속 참조할 수 있지만 현재 제공에 여전히 적용할 수 있습니다.

이 릴리스 노트에는 Adobe Experience Manager용 XML Documentation 3.8.x 릴리스의 주요 새로운 기능 및 개선 사항이 나열되어 있습니다.

## 3.8.5 릴리스의 새로운 기능 및 개선 사항

### 버그 수정

3.8.5 릴리스에서 수정된 버그는 다음과 같습니다.

- FrameMaker Publishing Server을 통한 PDF 출력에 대한 기준선 지원이 누락되었습니다.
- AEM의 여러 그룹에 대해 폴더 수준 권한이 설정된 경우 FrameMaker 또는 Oxygen용 체크아웃 및 체크인 API가 제대로 작동하지 않습니다.
- Assets UI 페이지에서 컨텐츠 미리 보기가 표시되지 않습니다.
- Assets UI 페이지에서 &#39;Source&#39; 버튼이 작동하지 않습니다.
- 웹 편집기의 이미지 삽입 기능을 통해 이미지를 삽입하면 삽입된 이미지의 상대 경로가 절대 경로로 변경됩니다.
- FMPS 사전 설정 드롭다운 목록은 최신 3.8 릴리스의 UI에 표시되지 않습니다.
- DAM에 많은 자산이 포함되어 있고 XML Web Editor에서 새 즐겨찾기 항목이 추가되면 즐겨찾기 패널이 표시되지 않습니다.
- 모든 링크를 리디렉션하는 내부 리디렉션 *sling:mapping*&#x200B;이(가) 작동하지 않으며 웹 페이지의 짧은 URL 대신 긴 URL(내부 경로 포함)을 표시합니다.
- 목록 보기에서 Assets UI 페이지에서 에셋을 업로드하거나 가져올 때(패키지 관리자를 통해 제외) 수정됨 열에 사용자 이름 대신 &#39;외부 사용자&#39;가 표시됩니다.
- 맵 대시보드의 주제 탭에 제목이 올바르게 표시되지 않습니다.
- 노드 병합 기능을 활성화하면 원하지 않는 정크 문자가 HTML 출력에 저장됩니다.
- 사용자 환경 설정에서 폴더 프로필의 변경 사항은 이미 열려 있는 파일에 대해 자동으로 다시 로드되지 않지만 브라우저를 새로 고쳐야 합니다.
- 일부 유효성 검사 오류가 있는 경우 맵 다운로드 옵션을 통해 생성된 출력에 누락된 항목이 있습니다.

## 3.8 릴리스의 새로운 기능 및 향상된 기능

### 파일 이름 지정 구성 업데이트

XML Documentation 솔루션에서 DITA 주제를 만드는 동안 사용자는 파일 이름의 일부로 특수 문자를 사용할 수 있습니다. 그 결과 AEM 사이트 페이지를 생성할 때 URL이 인코딩되었습니다. URL에서 이 변환이 발생하지 않도록 하기 위해 XML Documentation 솔루션 3.8 릴리스를 사용하면 관리자가 기본 유효한 파일 이름 구성(a-z A-Z 0-9 - _)이 아닌 특수 문자 목록을 정의할 수 있습니다. 이는 공백을 포함하여 파일 이름에 특수 문자 목록을 구성할 수 있지만 하이픈(-)으로 대체됨을 의미합니다.

### AEM 사이트 페이지 이름 생성 변경 사항

작성 중에 서로 다른 폴더에 있는 하나 이상의 파일에 대해 동일한 파일 이름을 사용할 수 있습니다. AEM 사이트 게시 프로세스 중에 적어도 중복 파일 이름이 있는 경우 페이지 이름에 접미사가 붙습니다. XML Documentation 솔루션의 3.8 릴리스를 통해 AEM 사이트 페이지 이름 생성 프로세스가 수정되었습니다. 접미사는 중복 파일 이름이 있는 경우에만 생성된 페이지 이름에 추가됩니다.

#### 게시

- **생성된 사이트 페이지에 대한 정리 규칙 구성 허용**: 관리자는 생성된 AEM 사이트 또는 DITA-OT 출력의 파일 이름에 대한 정리 규칙을 정의할 수 있습니다. DITA-OT를 사용하여 AEM 사이트 출력 또는 출력을 생성할 때마다 아래 규칙을 구성하여 출력 생성 URL 또는 파일 이름을 정리할 수 있습니다.
   - 모든 문자를 소문자로 변환합니다.
   - 특수 문자를 구분자로 바꿉니다.
   - 긴 파일 이름을 사전 정의된 문자 수로 제한합니다.

- 일괄 활성화 대시보드를 사용하여 작성자 인스턴스의 출력을 게시 인스턴스로 쉽게 푸시할 수 있습니다. 단일 맵 또는 맵 컬렉션으로 작업하고 게시하는 데 사용할 출력 사전 설정을 선택할 수 있습니다.

  ![일괄 게시 대시보드](assets/bulk-publish-dashboard.avif)

#### 성능 향상

- AEM Sites 출력에 대한 노드 병합: 이전에 AEM Sites 출력의 사이트 노드 구조가 너무 깊었습니다. 이제 더 나은 성능을 위해 노드 구조를 평면화하도록 제어할 수 있습니다.
- FrameMaker Publishing Server 2020 여름 릴리스의 최신 릴리스에 대한 지원.
- 이제 번역 중에 생성된 임시 파일이 제거되어 번역 프로세스가 향상됩니다.

#### 기타 개선 사항

- DITA 컨텐츠를 후처리하는 동안 DAM 자산 업데이트 워크플로우의 종속성이 제거되었습니다. DAM 자산 업데이트 워크플로우에 정의된 사용자 지정 프로세스 단계가 있는 경우 사후 처리가 완료된 후 실행할 프로세스 단계를 업데이트해야 합니다.
- 이제 번역 작업이 성공적으로 생성되면 번역 프로세스의 개시자가 받은 편지함에서 알림을 받게 됩니다.

### 버그 수정

3.8 릴리스에서 수정된 버그는 다음과 같습니다.

- 오디오 개체는 HTML 출력에 표시되지 않습니다.
- DITA 주제를 삭제할 때 표시되는 강제 삭제 창에는 여러 &#39;강제 삭제&#39; 단추가 표시됩니다.
- 기준 요소를 언어 사본으로 전송하면 서버측 보기를 사용하여 생성된 기준 요소에 대해 작동하지 않습니다.
- 주제의 버전 3.0이 나란히 표시되는 보기에서 3으로 표시되어 검토 설명을 가져올 수 없는 경우가 있습니다.
- 이동된 DITA 맵의 기준선 탭에서 참조된 콘텐츠 세부 정보를 느리게 로드합니다.
- 비DITA 자산에 대해서는 이전 버전으로 되돌릴 수 없습니다.
- AEM Sites 출력 생성으로 빈 _text 노드가 많이 생성되고 있습니다.
- XML 편집기 - 페이지 생성 후 이미지 맵의 링크 확인이 작동하지 않습니다.
- [기준선] 탭에서 레이블 적용은 이미지와 같이 참조된 콘텐츠에 레이블을 추가하지 않습니다.
- SVG 파일이 맵 다운로드 옵션을 통해 잘못된 형식으로 다운로드되고 있습니다.
- 목록 보기에서 콘텐츠 조각을 편집할 수 없습니다.
- 커넥터를 사용하여 Oxygen XML 작성자 내에서 파일을 체크 아웃하고 열 수 없습니다.
- 작성 보기에 `<alt>` 요소 텍스트가 표시되지 않습니다.
- 이미지 자산은 번역된 사본이 존재하는 경우에도 항상 최신 상태가 아닌 것으로 표시됩니다.
- 사용자 지정 맵 템플릿 제목이 올바르지 않고 썸네일이 표시되지 않습니다.
- 적용된 브랜드 마크 요소가 웹 편집기의 작성 보기에 표시되지 않습니다.
- 연결된 각주는 콘텐츠에 표시되지 않습니다.
- 웹 편집기의 색상 코딩은 특수 조건부 특성에서 작동하지 않습니다.
- @keyref에 대한 드롭다운 목록은 @keyref 수가 많은 고객의 경우 거의 사용할 수 없다고 간주하여 사용자에게 친숙하지 않습니다.
- JavaScript에서 참조한 변수 @keyref은 렌더링되지 않습니다.
- 산소 연결기 || &quot;Edit in Oxygen&quot; 버튼을 누르면 파일이 체크 아웃되지 않은 경우에도 편집 모드로 파일이 열립니다.
- 사용자 지정 맵 템플릿으로 사용자 지정 출력 사전 설정을 만들지 않습니다.
- Microsoft Word(.docx)에서 DITA로의 변환이 jcr:content 노드를 생성하지 않고 폴더 이름에 특수 문자를 허용합니다.
- 150개가 넘는 참조가 있는 MAP이 이동되면 참조가 중단되고 항목을 여는 동안 오류가 관찰됩니다.
- 이미지 너비를 변경하면 이미지 해상도가 잘못 계산됩니다.
- `<codeblock>`에 이미지를 추가하면 AEM 사이트 출력에 원하지 않는 공백이 표시됩니다.
