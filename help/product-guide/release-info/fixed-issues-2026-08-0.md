# 2026.08.0 릴리스의 문제가 해결되었습니다.

이 문서에서는 Adobe Experience Manager Guides as a Cloud Service의 2026.08.0 릴리스의 다양한 영역에서 수정된 버그를 다룹니다.

새로운 기능 및 향상된 기능에 대한 자세한 내용은 [2026.08.0 릴리스의 새로운 기능](whats-new-2026-08-0.md)을 참조하세요.

[2026.08.0 릴리스의 업그레이드 지침](upgrade-instructions-2026-08-0.md)에 대해 알아봅니다.

## 작성

- 맵 대시보드의 주제 보고서에서 액세스할 때 편집기에서 주제가 열리지 않습니다. (GUIDES-45277)


## 편집기 2.0

- MathML 방정식이 `conref`(으)로 삽입되면 올바르게 렌더링되지 않습니다. (GUIDES-46601)
- `<keydef>` 또는 `<topicref>` 내에서 `<topicmeta>` 내의 `<keywords>`을(를) 복사하여 붙여넣으면 키워드가 원치 않는 외부 태그 내에 삽입됩니다. (GUIDES-45800)
- 맵 편집기에서 끊어진 링크에 `Ctrl+click`을(를) 사용하면 응용 프로그램 오류가 트리거됩니다. (GUIDES-45544)
- Excel 스프레드시트에서 표를 복사하여 새 편집기에 붙여넣으면 복사된 모든 셀 콘텐츠가 해당 셀에 분산되지 않고 단일 테이블 셀에 배치됩니다. (GUIDES-47435)
- `editor_toolbar.json`을(를) 통해 구성된 사용자 지정 **PDF으로 내보내기** 단추가 렌더링되고 미리 보기 모드에서 클릭 가능한 상태로 유지되지만 클릭할 때 작업을 수행하지 않습니다. (GUIDES-47402)
- MathML 및 SVG 요소는 전체 속성 세트를 렌더링하지 않으므로 사용자 지정 CSS 클래스와 이러한 요소에 적용된 조건부 속성이 중단됩니다. (GUIDES-46371)
- 테이블이 포함된 특정 주제를 열면 주제가 변경되지 않았더라도 두 개의 새 열이 있는 예기치 않은 `<foreign>` 태그가 추가됩니다. (GUIDES-46748)
- 작성자 보기의 이미지에는 **Scale** 특성이 적용되지 않습니다. (GUIDES-45996)
- `keyref`이(가) 포함된 요소를 끌어다 놓으면 `keyref` 값이 절대 경로로 변환됩니다. (GUIDES-45701)
- `tgroup` 위치에 요소를 삽입하면 **이(가) 여기에서는 허용되지 않습니다#text** 경고가 표시되어 해당 위치에 일반 테이블이 삽입되지 않습니다. (GUIDES-47446)
- 사전에 추가된 영숫자 용어는 무시되지 않고 AEM 맞춤법 검사기에 의해 플래그가 지정됩니다. (GUIDES-48587)

## 자산 관리

- 일괄 에셋 처리에 콘텐츠 조각 에셋이 잘못 포함되어 처리 보고서에 오류 로그 및 오류가 발생합니다. (GUIDES-47085)
- 맵 패널에서 맵 확인란을 선택하고 선택을 취소하는 작업을 반복하면 하위 항목이 로드되지 않고 확장 아이콘이 사라집니다. (GUIDES-43546)

## 게시

**AEM Sites**

복합 구성 요소 매핑을 사용하여 AEM Sites 출력을 게시할 때:

- 합성 구성 요소 매핑을 사용하여 AEM Sites 사전 설정에서 새 기준선을 사용하면 빈 **주제 목록**&#x200B;이 표시됩니다. (GUIDES-46480)
- PDF, ZIP, DOCX 및 이미지 파일과 같은 비 DITA 자산에 대한 상호 참조(`xref`) 링크가 올바르게 확인되지 않아 생성된 페이지에서 링크가 끊어집니다. (GUIDES-44108)

이전 구성 요소 매핑을 사용하여 AEM Sites 출력을 게시할 때:

- 생성된 페이지 이름에서 영어가 아닌 파일 이름은 하이픈으로 대체되므로 연결된 주제나 파일을 식별하기가 어렵습니다. (GUIDES-48387)

**기본 PDF**

- 기본 PDF 출력에서 `toc="no"` 특성으로 표시된 항목 참조가 TOC에 포함되어 있어 목차가 길고 복잡합니다. (GUIDES-37940, GUIDES-20156)

**컬렉션 매핑 및 벌크 활성화**

Experience Manager Guides의 2020.08.0 릴리스에서 사용할 수 있는 [새 맵 컬렉션](../user-guide/generate-output-use-new-map-collection-output-generation.md#use-new-map-collection-for-output-generation-beta) 기능으로 다음 문제가 해결되었습니다.

- 네트워크 오류로 인해 맵 항목이 100개를 초과하는 맵 컬렉션을 로드할 수 없습니다. (GUIDES-34007)
- 맵 컬렉션 UI의 폴더에서 한 번에 여러 맵을 선택할 수 없습니다. (GUIDES-29581)
- 맵 컬렉션 UI에서 맵 컬렉션을 검색하거나 필터링할 수 없습니다. (GUIDES-27723)
- 브라우저의 뒤로 단추를 사용하지 않고 벌크 게시/활성화 대시보드를 닫거나 **도구** 또는 홈 페이지로 다시 이동할 수 없습니다. (GUIDES-26797)
- 많은 수의 맵 또는 언어로 맵 컬렉션을 쉽게 관리할 수 없음. (GUIDES-21735)
- 맵 컬렉션 또는 벌크 활성화 대시보드 인터페이스에서 직접 생성된 출력을 보거나 게시할 수 없습니다. (GUIDES-18712)
- 맵 컬렉션 과 벌크 활성화 대시보드는 별도의 컬렉션 세트를 관리하므로 단일 컬렉션을 사용하여 맵을 생성하고 활성화할 수 없습니다. (GUIDES-12730)

## 검토

- 리뷰 UI에서 태그 지정 목록에는 리뷰 작업에 있는 모든 사용자가 표시되므로 댓글이나 답글에서 올바른 사용자를 선택하기 어렵습니다. (GUIDES-33420)
- [주석] 패널에서 **나란히** 보기를 열면 주석이 있는 버전과 함께 작업 복사본이 표시되지만 창이 가로로 동기화되어 스크롤되지 않으며 주석을 클릭해도 커서가 해당 텍스트로 이동하지 않습니다. (GUIDES-44083)

## 데이터베이스

- `DatabaseConfiguratorService`이(가) 구성되거나 활성화되지 않은 경우에도 로그에 오류가 발생합니다. (GUIDES-43481)

## 알려진 문제

Adobe은 2026.08.0 릴리스에 대해 다음과 같은 알려진 문제를 확인했습니다.

## 작성

- 다른 위치로 이동한 DITAVAL 파일을 닫으면 `ERROR IN FETCHING VERSION DETAILS` 오류 메시지가 표시됩니다. (GUIDES-51420)
- 충돌 API가 실패하고 저장소 폴더 경로가 슬래시로 끝나는 경우 애플리케이션 오류가 발생합니다. (GUIDES-51006)

## 편집기 2.0


- 개요 보기에서 처리 명령 요소를 선택하면 선택한 요소 대신 전체 상위 태그가 강조 표시됩니다. (GUIDES-48318)
- 소스 보기에서 `keyref` 내의 키워드를 편집하면 보기가 다른 보기로 전환될 때 키워드가 끊어집니다. (GUIDES-49998)
- `foreign` 및 `equation` 블록 안에 래핑된 MathML 방정식은 원하지 않는 간격을 발생하며 수식 안에 입력하면 들여쓰기를 조정한 후에도 문제가 발생합니다. (GUIDES-46606)
- 편집기 설정에서 **태그 표시** 옵션을 사용하고 **특성 표시** 옵션을 사용하지 않도록 설정한 경우 `reltable` 내의 `topicref` 내에 커서를 배치할 수 없습니다. (GUIDES-46565)

- 테이블 셀 `<entry>` 내의 인라인 태그가 삭제되기 바로 전에 입력한 공백입니다. (GUIDES-49144)

## 게시

- Edge Delivery Services 출력을 생성한 후 **출력 보기**&#x200B;를 선택하면 `aem.live` URL 대신 403 금지된 오류를 반환하는 `hlx.live` URL이 열립니다. (GUIDES-51572)
- 템플릿의 도구 모음에서 이미지, 하이퍼링크 또는 iframe을 추가할 때 `common.plt` 페이지에 잘못된 구성 요소가 표시됩니다. (GUIDES-51165)
- `copy-to` 특성을 사용하여 항목을 참조하는 맵을 게시하면 원본 맵의 해당 항목에서 피어 범위 링크가 제거됩니다. (GUIDES-50701)
- PDF이 범위가 `Peer`(으)로 설정된 `xref`(으)로 참조되는 경우 교차 맵에서 소스로 제공되는 대신 기존 구성 요소 매핑을 사용하여 AEM 사이트에 게시됩니다. (GUIDES-50213)

**컬렉션 매핑**

- 맵 컬렉션을 삭제하기 전에 탭(예: 저장소 또는 개요)을 전환한 다음 맵 컬렉션 페이지로 돌아가면 경우에 따라 맵 컬렉션을 삭제하지 못합니다. (GUIDES-50997)
- 이전 생성이 진행 중일 때 동일한 사전 설정을 생성하면 더 이상 이전 생성이 진행 중임을 나타내는 메시지가 표시되지 않습니다. (GUIDES-50523)
- 맵이 생성된 후에는 마지막 생성 타임스탬프가 맵 컬렉션 UI에 표시되지 않거나 업데이트되며, 이전에 제거된 사전 설정을 다시 추가하면 해당 생성 기록이 다시 손실됩니다. (GUIDES-50511)
- **생성 기록**&#x200B;에서 게시하면 항상 선택한 생성 대신 사전 설정의 최신 출력이 게시됩니다. (GUIDES-50508)
- 새로 생성된 맵 컬렉션에 대해 게시 상태가 자동으로 새로 고쳐지지 않습니다. (GUIDES-50367)

## 번역

- **구조만 만들기** 옵션으로 번역을 시작하면 오류가 반환됩니다. (GUIDES-51261)

## 검토

- 숨겨진 조건부 콘텐츠가 포함된 텍스트 위에 키보드 단축키를 사용하여 취소선을 수행하면 숨겨진 콘텐츠도 취소됩니다. (GUIDES-49837)
