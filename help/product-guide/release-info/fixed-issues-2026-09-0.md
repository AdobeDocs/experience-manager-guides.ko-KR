# 2026.09.0 릴리스의 문제가 해결되었습니다.

이 문서에서는 Adobe Experience Manager Guides as a Cloud Service의 2026.09.0 릴리스의 다양한 영역에서 수정된 버그를 다룹니다.

새로운 기능 및 향상된 기능에 대한 자세한 내용은 [2026.09.0 릴리스의 새로운 기능](./whats-new-2026-09-0.md)을 참조하세요.

[2026.09.0 릴리스의 업그레이드 지침](./upgrade-instructions-2026-09-0.md)에 대해 알아봅니다.

## 편집기 2.0

- 작성자 모드에서 표를 복사하여 작성자 모드로 붙여넣으면 `colwidth`과(와) 같은 특성과 `colspec`에 정의된 다른 특성이 제거되어 열 너비 설정이 손실됩니다. (GUIDES-52916)
- 테이블 셀 `<entry>` 내의 인라인 태그가 삭제되기 바로 전에 입력한 공백입니다. (GUIDES-49144)

## 작성

이 섹션에서는 편집기 1.0 및 편집기 2.0에 공통되는 작성 시 수정된 버그를 다룹니다.

- 저해상도 화면에서는 도구 모음에서 키워드를 삽입할 때 키워드 삽입 대화 상자가 표시되지 않지만 **자세히** 옵션을 사용할 때는 예상대로 열립니다. (GUIDES-48304)
- Schematron 유효성 검사가 빈 규칙 파일로 구성된 경우 주제를 저장하면 부정확한 일반 오류 메시지가 표시됩니다. (GUIDES-48106)
- 텍스트 노드 컨텍스트를 사용하는 스키마 규칙은 유효성 검사를 트리거하지 않습니다. (GUIDES-14500)
- **웹 링크** 옵션을 사용하여 상호 참조를 삽입하면 예상대로 `scope=external`을(를) 삽입하는 대신 `scope=local` 링크가 추가되고 `href` 값이 수정됩니다. (GUIDES-48457)
- 참조 맵을 저장하면 한 작성자가 참조된 맵을 이동하는 동안 다른 작성자가 저장되지 않은 맵에서 해당 맵에 대한 참조를 동시에 추가할 때 올바른 맵으로 확인되지 않고 참조가 손상됩니다. (GUIDES-47467)

## 자산 관리

- 에셋 상태 API는 경로에 쉼표가 포함된 에셋에 대해 올바른 상태를 반환하지 않습니다. (GUIDES-49065)
- Assets 관리 검색 레일의 DITA 요소 필터는 입력한 값을 적용하지 않으므로 검색 결과가 필터링되지 않습니다. (GUIDES-48450)
- 버전 제거 유틸리티는 제거를 완료하고 정확한 보고서를 생성하는 대신 특정 파일 유형, 메타데이터가 누락된 에셋 및 큰 보고서를 비롯한 여러 시나리오에서 완료되지 않습니다. (GUIDES-43453)
- Assets UI에서 이동 작업을 사용하여 GUID 기반 파일 이름이 있는 에셋의 이름을 다른 GUID로 바꾸면 에셋의 원래 고유 GUID가 새 GUID로 바뀝니다. (GUIDES-43006)

## 게시

- 이전 버전을 타깃팅하는 기준선과 함께 AEM Sites(복합 구성 요소 매핑) 출력을 생성하면 페이지 컨텐츠에 이전 버전이 올바르게 표시되지만 페이지 메타데이터에는 대신 현재 버전이 표시됩니다. (GUIDES-49325)
- 벌크 활성화를 사용하여 페이지를 복제하는 경우 복제 추적 속성이 하위 페이지가 아닌 루트 페이지에서만 설정되므로 마지막 복제 이후 변경된 콘텐츠를 확인하기 어렵습니다. (GUIDES-37871)
- 기준선 만들기/편집 대화 상자의 **레이블** 필드에 처음으로 포커스가 지정되면 첫 번째 문자를 붙여넣거나 입력해도 자동 완성 제안이 올바르게 필터링되지 않고 필드에 필터링된 결과 대신 모든 제안이 표시됩니다(GUIDES-50143).
- 분기 필터링은 `keydef`(DITA-OT에 의해 `resource-only ="true"`(으)로 표시된) 원치 않는 주제에 대한 추가 페이지를 생성합니다. (GUIDES-19701)
- 맵 컬렉션을 사용하면 아직 생성되지 않은 사전 설정에 대해 **게시** 옵션을 사용할 수 있습니다. (GUIDES-50510)
- 새로 만든 맵 컬렉션에 게시 레코드가 없으면 게시 내역 섹션에 자리 표시자 텍스트가 표시되지 않습니다. (GUIDES-50366)
- 기본 PDF 사전 설정에 ICC 색상 프로파일을 적용하면 출력 생성에 실패하고 직접 프로파일 경로를 사용하는 경우에도 CMYK 색상이 올바르게 렌더링되지 않습니다. (GUIDES-47137)
- 기본 PDF 사전 설정에 구성된 도련 설정은 생성된 출력에 반영되지 않습니다. (GUIDES-47034)
- 테이블 연속에 대한 **나누기 전 텍스트** 필드는 지역화된 문자열만 렌더링하고 페이지 번호 자리 표시자를 대체하지 않습니다. (GUIDES-32872)
- ICC 프로파일 브라우저에는 ICC 파일만 표시되지 않고 DITA 파일이 잘못 표시됩니다. (GUIDES-25017)
- 초안 주석은 기본 PDF 출력에서 렌더링되지 않습니다. (GUIDES-47044)
- `title` 요소 내부에 있는 초안 주석이 게시된 출력에 예기치 않게 나타납니다. (GUIDES-10686)
- 맵 대시보드에서 다른 사전 설정을 선택하면 피어 링크를 가져오는 호출이 트리거되어 추가 처리가 발생합니다. (GUIDES-53703)

## 번역

- XLIFF 프로젝트를 사용하여 번역을 시작하면 진행 중 상태로 이동하지 않는 빈 프로젝트가 만들어집니다. (GUIDES-51759)
- 에셋 이동 작업을 사용하여 콘텐츠를 한 언어 폴더에서 다른 언어 폴더로 이동하면 작성자가 번역 패널에서 번역할 콘텐츠를 선택할 수 없습니다. (GUIDES-49386)
- 동일한 프로젝트에 대한 다른 번역 요청(새 프로젝트 만들기 또는 *기존 번역 프로젝트에 추가* 요청)이 아직 처리 중일 때 **기존 번역 프로젝트에 추가** 옵션을 사용하여 번역용 자산을 보내는 경우 충돌이 발생합니다. (GUIDES-49354)

## 베이스라인

- 기준선을 삭제한 후 또는 동적 기준선을 만드는 동안 사전 설정의 저장된 기준선 선택 사항이 *기준선 없음*(으)로 잘못 표시됩니다. (GUIDES-52690)

## 검토

- [검토] 패널을 열거나 프로젝트 필터를 적용하면 작업 목록을 로드하는 데 시간이 조금 걸립니다. (GUIDES-48893)

## 보고서

- 많은 주제가 포함된 맵에 대해 끊어진 링크 보고서를 생성하면 보고서 인터페이스가 **끊어진 링크에 대한 세부 정보를 가져오는 중** 메시지에서 무기한 중단된 상태로 유지되어 브라우저가 응답하지 않고 결국 충돌이 발생합니다. (GUIDES-37845)

## 학습 콘텐츠

- HTML 또는 사용자 지정 헤더가 있는 학습 템플릿을 사용하여 새 학습 주제를 만들 때 주제 제목이 사용자 지정 헤더에 표시되지 않습니다. (GUIDES-52343)
- 과정 퀴즈의 계산된 정확도가 예상값과 약간 다릅니다. (GUIDES-52346)
- 물론 퀴즈를 시도할 때 채점된 점수는 예상 계산된 점수와 약간 다르다. (GUIDES-52345)

## 알려진 문제

Adobe은 2026.09.0 릴리스에 대해 다음과 같은 알려진 문제를 확인했습니다.

- 이미 잠긴 항목의 문서 상태를 변경하면 전체 문서가 새로 고쳐집니다. (GUIDES-53905)
- [기준 요소를 사용하여 미리 보기] 기능을 사용하는 경우 미리 보기는 큰 맵(10,000개 이상의 주제) 또는 `keydefs`의 수가 많은 맵(예: 100개 `keydefs` 및 3,500개 주제)에 대해 시간 초과를 요청합니다. (GUIDES-54147)
- DB 서버의 경우 `href`이(가) 없는 `keydef`이(가) 포함된 맵을 미리 볼 때 [기준 옵션을 사용하여 미리 보기]가 활성화된 경우 `keydef`이(가) 확인되지 않습니다. (GUIDES-53878)
- 이미지 맵 자산에 구성된 핫스팟 영역은 미리 보기 모드에서 대화형이 아니므로 작성자가 게시하기 전에 핫스팟 링크의 유효성을 검사할 수 없습니다. (GUIDES-53398)<br>**해결 방법**: 이미지 맵으로 변환할 이미지를 삽입하고 상황에 맞는 메뉴에서 **이미지 맵 편집**&#x200B;을 선택한 다음 핫스팟 링크를 구성합니다.
- 맵이 열려 있는 동안 기존 기준선이 있는 맵을 다른 폴더로 이동하면 **기준선을 사용하여 미리 보기** 토글이 미리 보기 모드에서 선택된 상태로 유지되지만, 기준선은 더 이상 드롭다운 목록에 표시되지 않습니다. (GUIDES-54284)<br>**해결 방법**: 맵을 닫았다가 다시 열어 문제를 해결할 수 있습니다.
- 새로 구성된 AEM Cloud Service 환경(AEM as a Cloud Service SDK)에서 맵 또는 주제 파일을 만들려고 하면 *파일을 만들지 못했습니다* 오류 또는 *DTD 규칙을 검색하는 동안 오류가 발생했습니다*. (GUIDES-53904)<br>**해결 방법**: AEM Cloud Service 환경을 다시 시작할 수 있습니다.
- 두 작성자가 동일한 주제를 동시에 작업할 때 한 작성자가 일정 기간 연 주제를 잠그면 다른 작성자가 변경한 후에도 버전 번호, 레이블, 문서 상태, 태그 등과 같은 메타데이터 속성이 새로 고쳐지지 않고 오래된 값이 계속 표시됩니다. (GUIDES-54810)<br>**해결 방법**: 항목을 닫았다가 다시 열어 메타데이터를 새로 고치고 최신 값을 표시합니다.
