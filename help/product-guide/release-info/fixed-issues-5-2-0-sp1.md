# 5.2.0 서비스 팩 1 릴리스의 문제가 해결되었습니다(2026년 9월)

이 문서에서는 Adobe Experience Manager Guides 5.2.0 서비스 팩 1 릴리스의 다양한 영역에서 수정된 버그를 다룹니다.

[5.2.0 서비스 팩 1 릴리스의 업그레이드 지침](upgrade-instructions-5-2-0-sp1.md)에 대해 알아봅니다.

## 작성

- 저해상도 화면에서는 도구 모음에서 키워드를 삽입할 때 키워드 삽입 대화 상자가 표시되지 않지만 **자세히** 옵션을 사용할 때는 예상대로 열립니다. (GUIDES-48304)
- **웹 링크** 옵션을 사용하여 상호 참조를 삽입하면 예상대로 `scope=external` 링크를 삽입하는 대신 `scope=local` 링크가 추가되고 `href` 값이 수정됩니다. (GUIDES-48457)
- 참조 맵을 저장하면 한 작성자가 참조된 맵을 이동하는 동안 다른 작성자가 저장되지 않은 맵에서 해당 맵에 대한 참조를 동시에 추가할 때 올바른 맵으로 확인되지 않고 참조가 손상됩니다. (GUIDES-47467)
- 사전에 추가된 영숫자 용어는 무시되지 않고 AEM 맞춤법 검사기에 의해 플래그가 지정됩니다. (GUIDES-48587)
- `in`, `mm` 또는 `px`과(와) 같은 단위 기반 크기를 사용하여 이미지 속성 대화 상자의 **Width** 및 **Height** 필드 간에 포커스를 전환하는 경우 값이 안정적으로 유지되지 않고 증분 방식으로 계속 증가합니다. (GUIDES-45929)

## 편집기 2.0

- 테이블 셀 `<entry>` 내의 인라인 태그가 삭제되기 바로 전에 입력한 공백입니다. (GUIDES-49144)
- `tgroup` 위치에 요소를 삽입하면 **이(가) 여기에서는 허용되지 않습니다#text** 경고가 표시되어 해당 위치에 일반 테이블이 삽입되지 않습니다. (GUIDES-47446)
- Excel 스프레드시트에서 표를 복사하여 새 편집기에 붙여넣으면 복사된 모든 셀 콘텐츠가 해당 셀에 분산되지 않고 단일 테이블 셀에 배치됩니다. (GUIDES-47435)
- `editor_toolbar.json`을(를) 통해 구성된 사용자 지정 **PDF으로 내보내기** 단추가 렌더링되고 미리 보기 모드에서 클릭 가능한 상태로 유지되지만 클릭할 때 작업을 수행하지 않습니다. (GUIDES-47402)
- 테이블이 포함된 특정 주제를 열면 주제가 변경되지 않았더라도 두 개의 새 열이 있는 예기치 않은 `<foreign>` 태그가 추가됩니다. (GUIDES-46748)
- MathML 방정식이 `conref`(으)로 삽입되면 올바르게 렌더링되지 않습니다. (GUIDES-46601)
- MathML 및 SVG 요소는 전체 속성 세트를 렌더링하지 않으므로 사용자 지정 CSS 클래스와 이러한 요소에 적용된 조건부 속성이 중단됩니다. (GUIDES-46371)
- 작성자 보기의 이미지에는 **Scale** 특성이 적용되지 않습니다. (GUIDES-45996)
- 테이블에 `scale` 특성을 적용하면 작성자 및 미리 보기 모드에서 구성된 크기로 테이블이 렌더링되지 않습니다. (GUIDES-45984)
- 페인트 또는 자르기 도구와 같은 외부 소스에서 복사한 이미지를 붙여넣으면 이미지가 주제에 삽입되지 않습니다. (GUIDES-45983)
- `<keydef>` 또는 `<topicref>` 내에서 `<topicmeta>` 내의 `<keywords>`을(를) 복사하여 붙여넣으면 키워드가 원치 않는 외부 태그 내에 삽입됩니다. (GUIDES-45800)
- 표의 태그 보기에서, 커서가 축소된 항목 태그 바로 아래에 있는 셀에 있을 때 위쪽 화살표 키를 누르면 축소된 태그가 건너뛰고 커서가 문서의 시작으로 이동합니다. (GUIDES-45408)
- 테이블 상황별 도구 모음에서 작업을 수행하면 예기치 않게 도구 모음이 닫히므로 후속 테이블 작업이 중단됩니다. (GUIDES-45405)
- **MathML 편집** 옵션이 읽기 전용 모드로 잘못 표시되거나 다른 사용자가 파일을 체크 아웃한 경우 파일을 편집할 수 없더라도 사용자가 MathML 콘텐츠를 업데이트할 수 있습니다. (GUIDES-45172)
- 개요 보기 또는 탐색 표시에서 **다음 항목 뒤에 삽입** 또는 **다음 항목 앞에 삽입**&#x200B;을 사용한 후 커서가 새로 추가된 태그 내부가 아닌 임의의 위치로 이동합니다. (GUIDES-45147)
- 태그 보기를 활성화한 상태로 드래그 앤 드롭을 수행할 때 부분 XML 또는 DITA 태그와 함께 컨텐츠를 선택하면 원하지 않는 고립된 태그가 뒤쳐져 잘못된 컨텐츠 또는 보기가 생성됩니다. (GUIDES-28191)

## 자산 관리

- 버전 제거 유틸리티는 제거를 완료하고 정확한 보고서를 생성하는 대신 특정 파일 유형, 메타데이터가 누락된 에셋 및 큰 보고서를 비롯한 여러 시나리오에서 완료되지 않습니다. (GUIDES-43453)

## 게시

- 생성된 페이지 이름의 영어가 아닌 파일 이름은 하이픈으로 대체되므로, 기존 구성 요소 매핑을 사용하여 AEM Sites 출력을 게시할 때 연결된 주제 또는 파일을 식별하기가 어렵습니다. (GUIDES-48387)
- DITA-OT 패키지에서 AEM Guides과 함께 번들로 제공되는 취약한 `jackson-databind` JAR(버전 2.9.8)가 식별됩니다. (GUIDES-43081)

## 검토

- [주석] 패널에서 **나란히** 보기를 열면 주석이 있는 버전과 함께 작업 복사본이 표시되지만 창이 가로로 동기화되어 스크롤되지 않으며 주석을 클릭해도 커서가 해당 텍스트로 이동하지 않습니다. (GUIDES-44083)

## Platform

- 항목 또는 맵 내에서 DAM 콘텐츠에 대한 참조에 `scope="external"`을(를) 사용하면 자산의 상대 경로가 GUID로 대체됩니다. (GUIDES-35605)
- UUID 마이그레이션 전에 만든 콘텐츠의 경우, **파일 계층 구조 유지** 및 **실제 파일 이름 사용** 옵션이 선택된 맵을 다운로드하면 원래 상대 파일 경로를 유지하는 대신 `scope="external"`을(를) 가진 `topicref`, `xref` 및 `conref` 요소의 `href` 값이 GUID 기반 파일 이름으로 잘못 변환됩니다. 그 결과 외부 참조가 끊어집니다. (GUIDES-46526)
- Assets UI를 통해 에셋을 업로드할 때 업로드 상태가 표시되지 않습니다. (GUIDES-7207)

## 알려진 문제

- 코드 블록 내에서 검토 작업을 수행할 때 **작업이 허용되지 않음** 경고가 첫 번째 시도에 표시되지만 반복하면 작업이 성공합니다. (GUIDES-56749)
- `code block`이(가) 포함된 콘텐츠에 대한 검토 작업을 만들 때 가져온 후 취소선 서식이 올바르게 적용되지 않으며 강조 표시된 콘텐츠가 나란히 표시되는 비교 보기에서 누락됩니다. (GUIDES-56811)
- 맵에 여러 주제가 포함되어 있더라도 보고서 패널의 **주제 목록** 탭에 결과가 표시되지 않는 경우가 있습니다. (GUIDES-56893) <br> **해결 방법:** 영향을 받는 콘텐츠를 다시 인덱싱하여 상위 맵 관계를 다시 빌드합니다. 그러면 항목이 주제 목록 탭에 예상대로 표시됩니다.
- 개요 보기에서 처리 명령 요소를 선택하면 선택한 요소 대신 전체 상위 태그가 강조 표시됩니다. (GUIDES-48318)
- 삭제 작업을 수행하는 동안 이미지 맵, 구조화된 요소, 인라인 서식 태그 및 병합할 수 없는 블록 간에 커서 이동 및 탐색의 일부 사소한 불일치가 발생하여 예기치 않은 커서 또는 삭제 동작이 발생할 수 있습니다. (GUIDES-46756)
- `foreign` 및 `equation` 블록 안에 래핑된 MathML 방정식은 원하지 않는 간격을 발생하며 수식 안에 입력하면 들여쓰기를 조정한 후에도 문제가 발생합니다. (GUIDES-46606)
- 편집기 설정에서 **태그 표시** 옵션을 사용하고 **특성 표시** 옵션을 사용하지 않도록 설정한 경우 `reltable` 내의 `topicref` 내에 커서를 배치할 수 없습니다. (GUIDES-46565)
- 읽기 전용 콘텐츠(예: conref 단락) 바로 다음에 나오는 단락 시작 부분에서 백스페이스를 누르면 편집 가능한 단락이 예기치 않게 삭제되거나 병합될 수 있으므로 편집 가능한 단락이 예기치 않게 삭제됩니다. (GUIDES-45049)
- 요소 이름 바꾸기 옵션을 사용하여 인라인 태그의 이름을 변경하면 이동 경로가 즉시 업데이트되지 않고 커서를 태그로 이동하거나 보기 모드를 변경한 후에만 변경 사항을 반영합니다. (GUIDES-44993)<br>**해결 방법:** 이동 경로를 업데이트하려면 인라인 태그의 이름을 바꾼 후 브라우저를 새로 고치십시오.
- Bodydiv와 같은 요소에 조건 표시기가 적용되면 표시기가 전체 태그 보기에서 인접 태그로 오버플로되어 잘못된 시각적 렌더링이 발생합니다. (GUIDES-44971)
