# Experience Manager Guides 기술 자료

기술 자료에는 핵심 제품 설명서 이상의 일반 구성, 사용자 지정 및 사용 사례에 대해 설명하는 Experience Manager Guides에 대한 실용적인 시나리오 기반 문서가 포함되어 있습니다.

| 범주 | 설명 |
|---|---|
| 작성 | 편집기 사용자 지정, 메타데이터 관리, 콘텐츠 유효성 검사를 포함하여 편집기에서 콘텐츠를 만들고 재사용하기 위한 팁과 기술입니다. |
| Guides 확장 프레임워크 | 확장 프레임워크 시작부터 사용자 정의 구성 요소 빌드, 위젯 및 앱 사용자 정의 검토까지 Experience Manager Guides UI를 사용자 지정하는 방법을 알아봅니다. |
| 외부 데이터 Source | Experience Manager Guides과 외부 데이터 소스 커넥터 통합 및 구성에 대한 지침입니다. |
| 게시 | 기본 PDF, DITA-OT, AEM Sites 템플릿 및 마이크로서비스 기반 게시 구성을 포함한 출력 생성에 대한 우수 사례입니다. |
| 워크플로 | 출력이 생성된 후 단계를 자동화하도록 사후 생성 워크플로우를 구성하고 사용합니다. |
| 번역 | 번역 성능을 개선하고 번역에 포함되거나 제외되는 콘텐츠를 관리하는 방법에 대한 지침입니다. |
| 사용 사례 | 조건부 콘텐츠, 키 작업 및 게시된 출력의 컨텍스트 콘텐츠 변수와 같은 실제 시나리오에 대해 알아봅니다. |
