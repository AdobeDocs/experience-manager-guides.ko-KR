# MCP - 규제 대상 기술 콘텐츠에 대한 액세스 확장

AI 기반 경험이 MCP(모델 컨텍스트 프로토콜)를 통해 기존 AEM 액세스 제어 및 권한을 준수하면서 자연어 요청을 통해 AEM Guides과 안전하게 상호 작용하는 방법에 대해 알아봅니다. 이 세션에서는 MCP 아키텍처, 구성, 인증 및 보안 모델을 설명하고 현재 지원되는 기능을 시연하며 실제 사용 사례, 현재 경계 및 주요 고려 사항을 살펴봅니다. 또한 AEM as a Cloud Service 및 온프레미스/AMS 환경에 대한 배포 고려 사항을 다루고, MCP 지원 클라이언트가 AEM Guides과 어떻게 연결할 수 있는지 시연하며, Adobe의 광범위한 AI 기능과 함께 MCP가 어디에 적합한지 논의합니다.


## 세션 개요

이 세션에서는 AEM Guides MCP를 설정, 구성 및 사용하는 방법에 대해 알아봅니다

## 핵심 사항

이 세션에서는 다음 작업을 수행할 수 있습니다.
- AEM Guides MCP 이해
- Cloud Service 및 온프레미스 배포 모두에 대한 정확한 설정 요구 사항 알아보기
- VS 코드, 클라우드 및 커서와 같은 AI 클라이언트를 AEM Guides에 연결하는 방법을 이해할 수 있습니다
- 현재 지원되는 MCP 기능 영역 이해
