# AI Assistant를 사용하여 콘텐츠 가져오기

AI Assistant의 에이전트 모드에서 **가져오기** 스킬을 사용하면 사용자 입력을 기반으로 DITA 맵을 생성하는 옵션을 사용하여 기존 PDF, Word 또는 Markdown 파일을 구조화된 DITA 주제로 변환할 수 있습니다. 컨텐츠를 다시 만들고, 구조화하고, 구성하는 데 필요한 수작업을 줄여 Adobe Experience Manager Guides에서 비정형 형식에서 구조화된 형식으로 컨텐츠를 간편하게 수집할 수 있습니다.

## 파일 가져오기

장치 또는 콘텐츠 저장소에서 파일을 가져오고, 새 주제의 시작을 정의하는 제목 수준을 지정하고, 가져온 콘텐츠의 대상 폴더를 선택할 수 있습니다. 파일을 가져오려면 다음 단계를 수행합니다.

1. Experience Manager Guides에 로그인.
1. 홈 페이지의 탐색 모음에서 **AI 길잡이**&#x200B;를 선택합니다. 관리자가 에이전트 모드에서 [AI 도우미](../install-conf-guide/workspace-settings.md)를 사용하도록 설정했는지 확인하십시오.
1. AI 도우미 패널에서 **가져오기**&#x200B;를 선택합니다. Word 파일의 경우 *이 docx를 DITA 주제로 변환* 또는 Markdown 파일의 경우 *이 Markdown을 DITA 주제로 변환*&#x200B;과 같은 다른 프롬프트를 사용할 수도 있습니다.

   시작 프롬프트 *첨부된 PDF 파일에서 콘텐트 가져오기를 도와주세요*&#x200B;이(가) 프롬프트 상자에 나타납니다.

1. 다음 방법 중 하나를 사용하여 프롬프트에 파일을 첨부합니다.

   - **바로 가기 사용**: 프롬프트 필드에 `/`을(를) 입력한 다음 **저장소 참조 추가**&#x200B;를 선택하여 리포지토리에서 파일을 선택합니다(또는 **장치에서 파일 추가**&#x200B;를 선택하여 컴퓨터에서 파일 업로드).

   - **파일 첨부 또는 컨텍스트 아이콘 추가 사용(+)**: 가져올 내용을 제공하기 위해 로컬 시스템에서 파일을 추가합니다.

   - **끌어다 놓기**: 가져올 파일을 시스템에서 프롬프트 공간으로 바로 끌어다 놓습니다.

     ![](images/attach-import.png)

1. **보내기**&#x200B;를 선택합니다.

   AI Assistant는 파일을 분석하고 완료된 각 단계를 나열합니다.

1. 가져온 항목을 저장할 폴더를 선택하고 확인합니다.

   ![](images/folder-import.png)

1. 주제가 되는 제목 수준을 선택합니다. 예를 들어 스크린샷에 표시된 H2입니다.

   가져오기 프로세스에 필요한 세부 정보를 제공하는 추가 후속 질문에 답변합니다.

   ![](images/heading-import.png)

1. **확인**&#x200B;을 선택합니다.

   AI 어시스턴트가 파일 변환을 시작합니다. 가져오기 스킬은 가져온 콘텐츠를 기반으로 작업, 문제 해결 등과 같은 적절한 DITA 주제 유형을 자동으로 식별하고 지정합니다.

1. 생성된 주제와 맵을 검토하려면 **미리 보기**&#x200B;를 선택하십시오.

   각 주제가 예상한 제목에서 시작되며 맵 순서가 원본 파일과 일치하는지 확인하십시오. Source 탭을 사용하여 가져온 데이터의 Source 코드를 확인할 수도 있습니다.

   ![](images/preview-import.png)

1. 다음 중 하나를 선택합니다.

   - 모든 주제와 맵을 확인한 폴더에 저장하려면 **수락**&#x200B;하세요.
   - 아무것도 저장하지 않고 가져오기를 취소하려면 **거부**&#x200B;하십시오. 가져오기를 거부하는 이유를 입력하고 원하는 변경 사항을 지정하는 프롬프트를 입력할 수 있습니다. AI Assistant는 사용자의 피드백을 사용하여 가져오기를 수정합니다.

   이제 저장소에서 주제 및 맵을 사용할 수 있습니다.

   ![](images/accept-reject-import.png)

전환이 완료되면 AI Assistant는 생성된 주제 및 맵의 미리보기를 엽니다. AI Assistant 대화 상자에서 해당 맵과 주제로 직접 이동할 수 있습니다.

## 붙여넣은 콘텐츠를 주제로 가져오기

웹 페이지, Word, Google Docs 또는 Wiki의 컨텐츠를 붙여넣으면 파일을 먼저 저장하지 않고 가져올 수 있습니다. 서식이 지정된 콘텐츠는 제목, 목록 및 표를 유지합니다.

붙여넣은 콘텐츠를 가져오려면

1. Experience Manager Guides에 로그인.
1. 홈 페이지의 탐색 모음에서 **AI 길잡이**&#x200B;를 선택합니다. 관리자가 에이전트 모드의 AI Assistant를 활성화했는지 확인합니다.
1. 웹 페이지, Word, Google Docs 또는 wiki에서 콘텐츠를 복사합니다.
1. 프롬프트 상자에 콘텐츠를 붙여넣습니다.

   2,000자가 넘는 형식이 지정된 콘텐츠는 Markdown으로 첨부되므로 구조는 전달됩니다.

   ![](images/pasted-import.png)

1. 원하는 콘텐츠를 지정하는 프롬프트를 입력합니다.

   예를 들어 *붙여넣은 페이지를 DITA로 가져오기* 또는 *붙여넣은 콘텐츠를 DITA 주제 및 맵으로 변환*&#x200B;을 입력합니다.

1. **보내기**&#x200B;를 선택합니다.

AI Assistant는 컨텐츠를 주제로 분할할 제목 수준을 선택하고 대상 폴더를 지정하라는 메시지를 표시합니다. 나머지 단계는 DITA 주제 및 맵을 생성하기 위해 가져오기 워크플로우를 검토 및 확인하는 작업을 포함하여 첨부 파일을 가져오는 것과 같습니다.
