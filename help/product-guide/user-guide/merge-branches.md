# 분기를 주 분기로 병합

Experience Manager Guides에서는 DITA 맵의 분기에서 `main` 분기로 변경 내용을 병합할 수 있습니다. 병합을 사용하면 변경 내용을 `main`에 수동으로 복사하지 않고 완료된 설명서 업데이트를 `main`에 통합할 수 있습니다.

예를 들어 이름이 `Release 2`인 분기가 있는 DITA 맵 `install-the-lift.ditamap`을(를) 고려해 보십시오. 작성자는 기존 설명서가 `main`에서 변경되지 않은 상태로 있는 동안 이 분기의 설치 지침을 업데이트할 수 있습니다.

업데이트가 준비되면 작성자가 `Release 2`의 변경 내용을 `main`에 병합할 수 있습니다.

## 분기 병합 이해

병합하면 DITA 맵의 선택한 분기에서 `main` 분기로 변경 내용이 적용됩니다.

- **Source 분기:** 병합할 변경 내용이 포함된 분기입니다.
- **대상 분기:** 변경 내용이 병합되는 기본 분기(`main`)입니다.

주제/맵의 동일한 부분이 두 분기에서 수정된 경우 병합 충돌이 발생하여 해결이 필요할 수 있습니다.

## 분기 병합

선택한 DITA 맵 분기의 변경 내용을 `main`(으)로 병합할 수 있습니다.

분기를 병합하려면 다음 단계를 수행하십시오.

1. 맵 콘솔에서 필요한 DITA 맵을 엽니다.
2. **분기** 탭으로 이동합니다.
3. 병합할 변경 내용이 포함된 분기를 찾습니다.
4. 분기의 **옵션** 메뉴를 열고 **메인으로 병합**&#x200B;을 선택합니다.

   ![](./images/merge-into-main.png)

   선택한 분기에 대해 병합 요청이 생성됩니다. 이를 통해 변경 내용을 검토하고 충돌을 해결한 후 `main`에 병합할 수 있습니다.

   ![](./images/merge-request-created.png)

5. 병합 요청을 선택합니다.

   병합 요청이 **병합 분기** 보기에서 열립니다. 변경 사항을 검토하고 필요한 경우 충돌을 해결합니다.
6. 병합을 완료합니다.

   변경 사항을 검토하고 필요한 경우 충돌을 해결합니다. 자세한 내용은 [병합 충돌 해결](#resolve-merge-conflicts)을 참조하십시오.

   모든 충돌이 해결되면 **모두 병합**&#x200B;을 선택하여 변경 내용을 `main`에 병합합니다.

   변경 내용이 `main` 분기에 병합됩니다.

## 병합 충돌 해결

`main`과(와) 병합되는 분기 모두에서 동일한 콘텐츠가 수정되면 병합 충돌이 발생합니다. 변경 내용을 `main`(으)로 병합하기 전에 모든 충돌을 해결해야 합니다.

병합 요청을 열면 **병합 분기** 보기에 다음 섹션이 표시됩니다.

![](./images/merge-branch-view.png)

- **충돌:** 충돌 해결이 필요한 파일을 나열합니다.
- **업데이트 정리:** 충돌을 해결하지 않고 병합할 수 있는 파일을 나열합니다.

충돌이 있는 파일의 경우 **분기 병합** 보기가 표시됩니다.

![](./images/merge-conflicts.png)

**분기 병합** 보기에는 다음 창이 포함되어 있습니다.

- **왼쪽 창(주):** 기본 분기(`main`)의 콘텐츠를 표시합니다.
- **가운데 창(병합됨):** 병합된 콘텐츠를 표시합니다. 이 경우 분기 중 하나의 변경 내용을 적용하거나 콘텐츠를 직접 편집할 수 있습니다.
- **오른쪽 창(선택한 분기):** `main`(으)로 병합되는 분기의 콘텐츠를 표시합니다.

**병합됨** 창의 내용을 기반으로 왼쪽 창과 오른쪽 창에서 차이점이 강조 표시됩니다.

- **빨강(-):** **병합됨** 창에 있는 콘텐츠 중 해당 왼쪽 또는 오른쪽 창의 콘텐츠와 다른 콘텐츠를 나타냅니다.
- **녹색(+):** **병합** 창에 포함되지 않은 왼쪽 또는 오른쪽 창에 있는 콘텐츠를 나타냅니다.

처음에는 **병합됨** 창에 `main`과(와) 동일한 콘텐츠가 포함되어 있으므로 오른쪽 창에 차이가 강조 표시됩니다. 선택한 분기의 변경 내용을 수락하면 왼쪽 창에 업데이트된 **병합됨** 창과 차이가 나타납니다.

병합 충돌을 해결하려면 다음 단계를 수행하십시오.

1. **충돌** 섹션에서 충돌이 포함된 파일을 선택하십시오.

   >[!NOTE]
   >
   > **업데이트 정리**&#x200B;에 나열된 파일에는 선택한 분기에서만 변경한 내용이 포함되어 있으므로 충돌 해결이 필요하지 않습니다.

2. **병합 분기** 보기에서 강조 표시된 차이점을 검토하고 병합 컨트롤을 사용하여 충돌을 해결하십시오.

   오른쪽 창의 충돌 옆에 있는 확인란은 선택한 분기 콘텐츠를 **병합** 창에 추가하는 방법을 결정합니다.

   - **선택됨(기본값):** **병합** 창의 일치하는 콘텐츠를 선택한 분기 콘텐츠로 바꿉니다.
   - **지워짐:** 선택한 분기 콘텐츠를 바꾸지 않고 **병합됨** 창에서 기존 콘텐츠와 함께 추가합니다.

   다음 옵션을 사용하여 충돌을 해결할 수 있습니다.

   - 선택한 분기의 변경 내용을 사용하려면 충돌에 대한 확인란을 선택한 다음 해당 왼쪽 방향 화살표 컨트롤(`<<<`)을 선택합니다. 선택한 분기 콘텐츠가 **병합됨** 창에서 충돌하는 콘텐츠를 대체합니다.

     ![](./images/replace-content-accept.png)

   - 두 분기의 콘텐츠를 유지하려면 충돌에 대한 확인란의 선택을 취소한 다음 왼쪽을 가리키는 화살표 컨트롤(`<<<`)을 선택합니다. 이렇게 하면 해당 창에 이미 있는 콘텐츠를 바꾸지 않고 선택한 분기 콘텐츠가 **병합됨** 창에 추가됩니다.

     ![](./images/keep-both-versions.png)

   - 선택한 분기의 변경 내용을 적용하고 `main`에서 해당 콘텐츠를 복원하려면 왼쪽 창에서 오른쪽 방향 화살표 컨트롤(`>>>`)을 선택합니다. **병합됨** 창에서 선택한 콘텐츠를 `main`의 버전으로 바꿉니다.

   >[!TIP]
   >
   > 선택한 변경 내용을 수락하면 **병합됨** 창에 어떤 영향을 주는지 보려면 화살표 컨트롤 위로 마우스를 가져갑니다.

3. 병합된 콘텐츠를 검토한 후 다음 옵션 중 하나를 사용하여 한 분기의 전체 콘텐츠를 수락할 수도 있습니다.

   - **주 항목 수락:** 선택한 파일의 **병합** 창에 있는 내용을 `main`의 버전으로 바꿉니다.
   - **분기 이름 [수락]:** 선택한 파일의 **병합** 창의 내용을 선택한 분기의 버전으로 바꿉니다.

   >[!NOTE]
   >
   > 두 옵션을 선택하면 충돌을 해결하는 동안 수동으로 변경한 내용을 포함하여 선택한 파일에 대한 **병합된 창**&#x200B;의 전체 내용이 바뀝니다.

   또는 **병합됨** 창에서 콘텐츠를 직접 검토하거나 편집한 다음 **해결됨으로 표시**&#x200B;를 선택하여 병합된 콘텐츠를 유지할 수 있습니다.

4. **병합됨** 창에서 최종 콘텐츠를 검토하고 **해결됨으로 표시**&#x200B;를 선택하여 파일을 해결됨으로 표시합니다.

5. **충돌**&#x200B;에 나열된 모든 파일에 대해 단계를 반복합니다.

   모든 충돌이 해결되면 **모두 병합** 옵션을 사용할 수 있습니다.

6. **모두 병합**&#x200B;을(를) 선택하여 해결된 파일과 완전한 업데이트를 `main`에 병합합니다.

   >[!NOTE]
   > 
   > 모든 충돌이 해결될 때까지 **모두 병합** 옵션이 비활성화됩니다.

   해결된 변경 내용이 `main`에 병합됩니다. 완료된 병합은 실행 취소할 수 없습니다. 그러나 새로운 병합 요청을 만들어 이후의 변경 내용을 주 항목에 병합할 수 있습니다.



## 병합 요청 관리

컨텍스트 메뉴를 사용하여 기존 병합 요청을 관리할 수 있습니다.

병합 요청을 관리하려면 컨텍스트 메뉴를 열고 다음 옵션 중 하나를 선택합니다.

- **미리 보기:** 병합 요청의 변경 내용을 병합하지 않고 표시합니다.
- **로그 보기:** 병합 요청과 연결된 로그를 봅니다.
- **삭제:** 병합 요청을 삭제합니다. 분기 및 해당 변경 사항은 영향을 받지 않습니다.
- **보고서 보기:** 분기가 `main`에 병합된 후 병합 보고서를 봅니다.
