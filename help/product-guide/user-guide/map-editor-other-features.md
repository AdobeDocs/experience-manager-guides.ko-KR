# 맵 편집기의 추가 기능 {#id1942D0T0HUI}

맵 편집기의 몇 가지 일반적인 기능은 다음과 같습니다.

## 키 참조 확인 {#id176GD01H05Z}

DITA 콘텐츠 키 참조 또는 `conkeyref`은(는) 한 주제의 콘텐츠 일부를 다른 주제에 삽입하기 위한 메커니즘입니다. 이 메커니즘은 키를 사용하여 직접 콘텐츠 참조 메커니즘이 아닌 재사용할 콘텐츠를 찾습니다. DITA의 직접 및 간접 참조에 대한 자세한 내용은 OASIS DITA 언어 사양의 *DITA 주소 지정*&#x200B;을 참조하십시오.

DITA 주제에 연관된 키 참조가 있는 경우 주제를 미리 보거나, 편집하거나, 검토하기 전에 키 참조를 해결해야 합니다.

주요 참조는 다음 우선 순위 순서로 설정된 루트 맵을 기준으로 확인됩니다.

1. 사용자 환경 설정
1. 맵 보기 패널
1. 폴더 프로필

사용자 환경 설정에서 선택한 루트 맵이 가장 우선하여 주요 참조를 해결한 다음 맵 보기 패널 및 폴더 프로필 루트 맵이 뒤따릅니다. 따라서 [사용자 환경 설정]에 맵이 설정되어 있지 않으면 [맵 보기] 패널에서 연 맵이 사용됩니다. 맵 보기 패널에서 맵이 열리지 않으면 폴더 프로필에 설정된 맵이 주요 참조를 확인하는 데 사용됩니다.

키 참조는 DITA 맵 파일이나 별도의 DITA 파일 내에 저장할 수 있습니다. Experience Manager Guides에서는 프로젝트 수준 또는 세션 수준에서 주요 참조를 지정할 수 있습니다. 사용자 세션에 대해 루트 맵이 이미 정의된 경우 키 확인에 사용됩니다. 그렇지 않으면 해당 폴더에 대한 기본 루트 맵이 사용됩니다. 기본 루트 맵이 구성되지 않은 경우 누락된 키 참조가 사용자에게 강조 표시됩니다.

다음 위치에서 사용할 DITA 맵을 정의하여 DITA 주제의 주요 참조를 해결하는 방법에는 여러 가지가 있습니다.

**프로젝트 속성** - 프로젝트 속성 섹션에서 프로젝트를 만드는 동안 키 참조를 확인하는 루트 맵을 정의할 수 있습니다.

이 루트 맵은 해당 프로젝트와 연결된 모든 자산 \(폴더 및 하위 폴더\)에 적용할 수 있습니다. 여러 프로젝트에서 참조되는 콘텐츠의 경우 알파벳 프로젝트 목록이 유지되고 첫 번째 프로젝트와 연결된 기본 루트 맵이 사용됩니다. 주요 참조를 확인하기 위해 목록에서 사용할 DITA 맵을 선택할 수도 있습니다.

**주제 미리 보기** - 주제 미리 보기 모드에서 도구 모음의 키 해상도 아이콘을 선택하고 키 참조에 사용할 DITA 파일을 선택합니다.

**주제 편집 보기** - DITA 주제를 편집하는 동안 키 확인 아이콘을 선택하고 키 참조를 확인하는 데 사용할 DITA 파일을 선택하십시오.

## 탐색 참조 추가

`navref` 요소는 다른 DITA 맵의 탐색 참조를 포함하는 데 DITA 맵 내에서 사용됩니다. 이를 통해 작성자는 참조된 맵의 실제 콘텐츠를 출력으로 병합하지 않고 공유 메뉴 또는 링크와 같은 탐색 구조를 재사용할 수 있습니다.

>[!NOTE]
>
> `navref` 요소는 맵 구조 내에서 탐색 목적으로만 사용됩니다. 생성된 DITA 맵 출력에 기여하지 않고 처리에서 제외되며 맵 보기, 보고서, 기준선, 변환 및 미리보기에서 표시됩니다.

맵에 탐색 참조를 추가하려면 다음 단계를 수행하십시오.

1. 탐색 참조를 추가할 DITA 맵 파일을 엽니다.

   맵 파일이 맵 편집기에서 열립니다.
1. 작성자 보기로 전환하고 커서를 탐색 참조에 적합한 위치에 놓습니다.
1. 도구 모음에서 **요소** 옵션을 선택합니다.
1. **요소 삽입** 대화 상자에서 **navref**&#x200B;을(를) 선택합니다.

   ![](./images/select-navref-element.png)
1. **경로 선택** 대화 상자가 표시됩니다. 지도에 탐색 참조로 포함할 맵 파일을 선택하고 **선택**&#x200B;을 선택합니다.

선택한 맵 파일의 탐색 참조가 지정된 위치에 추가됩니다. 또한 참조된 맵의 제목이 작성자 보기와 레이아웃 보기 모두에 표시됩니다.

![](./images/navref-added-author-view.png)

*작성자 보기*

![](./images/navref-added-layout-view.png)

*레이아웃 보기*

## 맵에서 상태 검사 실행

컨텍스트 메뉴의 상태 검사 실행 옵션을 사용하면 게시하기 전에 선택한 맵에서 상태 검사를 실행하여 끊어진 링크, 중복 ID 및 스키마 유효성 검사 실패와 같은 문제를 발견할 수 있습니다.

>[!NOTE]
>
> 이 기능은 기본적으로 활성화되어 있습니다. 사용자 환경에서 이 기능을 사용하지 않으려면 고객 지원 팀에 문의하십시오.

실행할 수 있는 검사는 관리자가 폴더 프로필 수준에서 만들고 관리하는 상태 검사 사전 설정으로 정의됩니다. 자세한 내용은 [상태 검사 사전 설정 만들기 및 관리](../install-conf-guide/conf-health-check-preset.md)를 참조하세요.

맵에서 상태 검사를 실행하려면 다음 단계를 수행하십시오.

1. 편집기에서 맵을 엽니다.
1. 옵션 메뉴에서 **상태 검사 실행** 옵션을 선택합니다.
   ![](./images/run-health-check-option.png)
1. 상태 검사 실행 대화 상자가 표시됩니다. 실행할 상태 검사 사전 설정을 선택합니다. 폴더 프로필에 대해 구성된 사전 설정만 선택할 수 있습니다.

   사전 설정을 선택하면 대화 상자에서 정의된 검사를 로드합니다.

   ![](./images/health-check-selected-checks.png)
1. *선택 사항* 기준선을 선택합니다. 기준선을 사용하지 않으려면 **없음**&#x200B;을 선택하세요.
1. **실행**&#x200B;을 선택합니다.

**상태 검사 보고서** 패널에서 맵에서 상태 검사를 실행할 수도 있습니다. 이렇게 하려면 맵 보기에서 맵을 열고 **상태 확인 보고서** 아이콘을 선택합니다.

![](./images/health-check-report-icon.png)

>[!NOTE]
>
>이 옵션은 아직 상태 검사가 실행되지 않은 맵에만 표시됩니다. 맵에서 상태 검사를 이미 실행한 경우 **상태 검사 보고서** 아이콘을 선택하면 기존 보고서가 대신 열립니다.

패널에서 **상태 검사 실행**&#x200B;을 선택합니다.

![](./images/run-health-check-report-panel.png)

위의 단계에 설명된 대로 맵에서 상태 검사를 실행할 수 있는 상태 검사 사전 설정 및 기준선을 선택할 수 있는 동일한 **상태 검사 실행** 대화 상자가 열립니다.

## 편집기에서 상태 확인 보고서 사용

맵에 대한 상태 검사를 실행하면 다음과 같이 **상태 검사 보고서** 패널에서 보고서가 열립니다.

![](./images/health-check-report-panel-editor.png)

### 상태 검사 보고서 패널 옵션

상태 확인 보고서 패널에서 다음 옵션을 사용할 수 있습니다.

- **맵 이름**: 보고서가 생성된 맵의 이름입니다.
- **정보 아이콘**: 보고서 생성에 사용되는 사전 설정 이름, 맵 버전 및 기준(있는 경우)을 보려면 선택하십시오.
- **필터**: 특정 규칙으로 보고서 범위를 좁힙니다. 예를 들어 끊어진 링크 결과만 볼 수 있습니다. 필터는 현재 보고서에서 결과를 생성한 규칙 유형만 나열합니다.
- **보고서 다운로드**: 보고서를 다운로드합니다.
- **다시 생성**: 상태 검사를 다시 실행합니다.

### 상태 확인 결과

선택한 검사에서 생성된 각 결과는 다음 세부 정보와 함께 나열됩니다.
- **심각도**: 결과의 심각도 수준(예: 오류, 경고, 정보 또는 치명적)입니다.
- **상태 검사 사전 설정 이름**: 보고서를 생성하는 데 사용되는 상태 검사 사전 설정 이름
- **규칙 이름**: 결과를 생성한 규칙입니다(예: 끊어진 링크 또는 중복된 ID).
- **줄 번호**: 문제가 발생하는 파일의 줄입니다.
- **자산**: 문제가 발견된 파일입니다.

결과를 선택하여 문제가 지속되는 정확한 줄에서 해당 파일을 엽니다.

![](./images/health-check-preset-report-selected.png)

>[!NOTE]
>
>끊어진 링크 결과는 파일을 작성자 모드로 엽니다. 중복 ID와 Schematron 유효성 검사 결과로 Source 모드에서 파일이 열립니다.

### 보고서 재생성

문제를 수정한 후 도구 모음에서 **다시 생성**&#x200B;을 선택하여 상태 검사를 다시 실행하고 문제가 해결되었는지 확인합니다. 표시된 **다시 생성** 대화 상자에서 다시 생성된 보고서에 포함할 검사를 선택합니다.

![](./images/health-check-preset-report-regenerate.png)

>[!NOTE]
>
> 상태 확인 보고서는 보고서를 생성한 사용자에게만 해당됩니다. 여러 사용자가 동일한 맵에 대한 보고서를 생성하면 각 사용자는 자체 결과를 봅니다. 그러나 관리자는 항상 맵에 대해 생성된 최신 보고서에 액세스할 수 있습니다.

### 보고서 다운로드

**보고서 다운로드**&#x200B;를 선택하여 모든 결과에 대한 자세한 정보를 포함하여 XLS 형식으로 보고서를 다운로드합니다.
