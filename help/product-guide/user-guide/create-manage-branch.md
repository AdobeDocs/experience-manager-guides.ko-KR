# DITA 맵의 분기 만들기 및 관리

Experience Manager Guides에서 DITA 맵의 여러 분기를 만들어 서로 다른 릴리스, 기능 또는 수정 사항에 대한 설명서를 관리할 수 있습니다. 분기 간에 전환하여 연결된 컨텐츠에서 작업하고, 더 이상 필요하지 않은 분기를 보관하고, 필요할 때 복원할 수 있습니다.

동일한 DITA 맵의 기존 분기에서 분기를 만들 수도 있습니다.

## 분기 만들기

다른 분기의 해당 콘텐츠에 영향을 주지 않고 문서 변경 작업을 위해 DITA 맵의 분기를 만들 수 있습니다.

분기를 만들려면 다음 단계를 수행하십시오.

1. 분기를 만들 DITA 맵을 엽니다.

   >[!NOTE]
   >
   > 편집기에 다른 맵이 이미 열려 있는 경우 확인 대화 상자가 나타납니다. 현재 분기에서 선택한 맵을 열려면 **열기**&#x200B;를 선택합니다. 자세한 내용은 [현재 맵 컨텍스트 외부에서 컨텐츠 열기](#open-content-outside-the-current-map-context)를 참조하십시오.

1. **main** 분기 드롭다운을 선택하고 필요한 DITA 맵이 선택되어 있는지 확인합니다.

   ![](./images/map-context-change.png)

1. 선택한 맵의 분기를 만들려면 **새 분기**&#x200B;를 선택하십시오.

1. **새 분기** 대화 상자에서 새 분기의 이름을 입력하고 분기를 만들 상위 분기를 선택합니다.

   ![](./images/new-branch-creation.png)

1. **만들기**&#x200B;를 선택합니다.

선택한 DITA 맵에 대해 새 분기가 만들어집니다. 이제 새 분기로 전환하고 관련 콘텐츠에서 작업을 시작할 수 있습니다.

## 분기 간 전환

분기를 전환하려면 다음 단계를 수행하십시오.

1. 편집기 맨 위에서 **분기 드롭다운**&#x200B;을(를) 선택합니다(기본적으로 `main`이(가) 표시됨). 선택한 DITA 맵에 사용할 수 있는 분기 목록이 표시됩니다.
1. 작업할 분기를 선택합니다.

   ![](./images/switch-branches.png)

   선택한 분기가 열리고 편집기 상단의 분기 드롭다운에 해당 이름이 나타나며 **main**&#x200B;을(를) 바꿉니다.

   ![](./images/branch-switched.png)

이제 선택한 분기 내에서 맵과 관련 콘텐츠를 작업할 수 있습니다.

![](./images/branch-switched.png)

>[!NOTE]
>
>분기를 전환할 때 항목에 저장되지 않은 변경 사항이 있으면 선택한 분기로 전환하기 전에 변경 사항을 저장하라는 대화 상자가 나타납니다.

이제 선택한 분기 내에서 맵과 관련 콘텐츠를 작업할 수 있습니다.

## 분기에서 격리된 편집

DITA 맵의 분기에서 작업할 때 해당 컨텐트에 대한 변경 사항은 선택한 분기 내에 유지되며 다른 분기의 해당 컨텐트에는 영향을 주지 않습니다. 이를 통해 여러 작성자가 맵의 서로 다른 분기에서 독립적으로 동일한 주제에 대해 작업할 수 있습니다.

기본적으로 변경되지 않은 항목은 원본 분기 또는 `main`에서 읽습니다. 선택한 분기에서 항목을 편집하면 해당 분기의 일부가 됩니다. 이후 항목의 변경 내용은 선택한 분기 내에 남아 있습니다.

동일한 DITA 맵의 분기 간에 전환하여 해당 콘텐츠를 보고 편집할 수 있습니다.

### 분기 내의 주제 편집

다른 분기의 콘텐츠에 영향을 주지 않고 선택한 분기의 DITA 맵과 연관된 주제를 편집할 수 있습니다.

항목을 편집하려면 다음 단계를 수행하십시오.

1. 편집기에서 DITA 맵을 엽니다.
2. 분기 드롭다운에서 주제를 편집할 분기를 선택합니다.
3. 맵에서 수정할 항목을 엽니다.
4. 주제에 필요한 변경 작업을 수행합니다.
5. 변경 사항을 저장합니다.

   수정된 주제의 사본은 선택한 분기에 저장됩니다. 다른 분기의 해당 주제는 변경되지 않습니다.

선택한 분기에서 주제 편집을 계속하거나 다른 분기로 전환하여 해당 콘텐츠를 작업할 수 있습니다.

### 현재 맵 컨텍스트 외부에서 맵 열기

Experience Manager Guides에서 **맵 컨텍스트**&#x200B;는 편집기에서 현재 열려 있는 DITA 맵을 참조합니다.

현재 맵 컨텍스트의 일부가 아닌 맵, 주제 또는 에셋을 열려고 하면 다음 옵션과 함께 확인 대화 상자가 표시됩니다.

- **열기:** 현재 맵 컨텍스트를 선택한 콘텐츠로 바꿉니다.
- **편집기에서 열기:** 현재 맵 컨텍스트를 변경하지 않고 새 탭에서 콘텐츠를 엽니다.
- **취소:** 작업을 취소하고 현재 맵 컨텍스트를 유지합니다.

예를 들어 `master_map.ditamap`이(가) 현재 **main** 분기에서 선택되어 있다고 가정해 보겠습니다.

![](./images/map-context-selection.png)

다른 DITA 맵을 열려고 하면 다음과 같은 확인 대화 상자가 나타납니다.

![](./images/open-map-context-dialog.png)

선택한 맵으로 전환하려면 **열기**&#x200B;를 선택합니다.

`main` 분기의 맵 컨텍스트가 새로 선택한 맵으로 업데이트되어 관련 콘텐츠로 작업할 수 있습니다.

![](./images/map-context-change.png)

### 현재 맵 컨텍스트 외부의 항목 열기 또는 편집

맵에서 참조하지 않는 주제는 분기에서 자동으로 사용할 수 없습니다.

![](./images/edit-topic-current-branch.png)

**현재 분기에서 편집**&#x200B;을 선택하여 선택한 분기에서 이러한 항목을 편집할 수 있도록 합니다.

이제 `main`의 내용에 영향을 주지 않고 항목을 편집할 수 있습니다. 그러나 주제가 연관된 DITA 맵에 자동으로 추가되지 않으며 게시된 출력에 포함되지 않습니다. 출력에 주제를 포함하려면 DITA 맵에 주제를 추가합니다.

## 분기 관리

맵 콘솔의 **분기** 패널에서 DITA 맵의 분기를 관리할 수 있습니다. 사용 가능한 분기를 보고, 새 분기를 만들고, 기존 분기를 병합하거나 이름을 바꾸고, 더 이상 활발하게 사용되지 않는 분기를 보관할 수 있습니다.

**분기** 패널에 선택한 DITA 맵에 사용할 수 있는 모든 분기가 나열됩니다.

![](./images/branches-panel.png)

분기를 관리하려면 필요한 분기 위로 마우스를 가져간 후 **옵션** 메뉴를 선택하십시오. 다음 작업을 사용할 수 있습니다.

![](./images/options-menu-branch.png)

- **새 분기:** 선택한 분기에서 새 분기를 만듭니다.
- **본에 병합:** [선택한 분기에서 `main` 분기로 변경 내용 병합](./merge-branches.md).
- **분기 이름 바꾸기:** 선택한 분기의 이름을 변경합니다.
- **병합 기록:** 병합 활동 기록을 표시합니다. 이 옵션은 병합 요청이 생성된 후에만 사용할 수 있습니다.
- **보관 분기:** 더 이상 사용되지 않는 분기를 보관합니다.

  >[!NOTE]
  >
  > Experience Manager Guides은 분기 삭제를 지원하지 않습니다. 더 이상 활발하게 사용되지 않는 분기를 보관할 수 있습니다.

**분기** 패널의 맨 위에 있는 옵션을 사용하여 분기를 검색하거나 분기 목록을 새로 고치거나 새 분기를 만들 수도 있습니다.

### 분기 보관

더 이상 활발하게 사용되지 않는 DITA 맵의 분기를 보관하고 필요할 때 복원할 수 있습니다.

>[!NOTE]
>
> 기본 분기(`main`)를 보관할 수 없습니다.

분기를 보관하려면 다음 단계를 수행하십시오.

1. **분기** 패널에서 **관리** 아이콘을 선택합니다.

   ![](./images/manage-branches-icon.png)

   **분기 관리** 대화 상자가 표시됩니다.

   ![](./images/manage-branches-dialog.png)

   이 대화 상자에는 다음 탭이 있습니다.

   - **활성:** 선택한 DITA 맵의 활성 분기를 모두 나열합니다.
   - **보관됨:** 선택한 DITA 맵의 보관된 분기를 모두 나열합니다.

2. **활성** 탭에서 보관하려는 분기를 마우스로 가리킨 다음 **보관**&#x200B;을 선택합니다.

   ![](./images/archive-branch.png)

   선택한 분기가 보관되어 **보관됨** 탭으로 이동됩니다.

### 보관된 분기 복원

콘텐츠 작업을 재개해야 할 때 DITA 맵의 보관된 분기를 복원할 수 있습니다.

보관된 분기를 복원하려면 다음 단계를 수행하십시오.

1. **분기** 패널에서 **관리** 아이콘을 선택합니다.
2. **분기 관리** 대화 상자에서 **보관** 탭을 선택합니다.
3. 복원할 분기를 찾은 다음 **복원**&#x200B;을 선택합니다.

   분기가 복원되고 **활성** 탭에 나타납니다.
