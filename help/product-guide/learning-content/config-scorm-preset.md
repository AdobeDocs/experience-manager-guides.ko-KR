# SCORM 출력 사전 설정 구성

사전 설정이 만들어지면 SCORM 사전 설정 설정을 구성합니다. 사전 설정된 구성 옵션은 일반, 콘텐츠, 학습자 경험 및 게시 탭 아래에 구성됩니다.

- **일반:** 구성된 모든 워크플로가 포함된 새 사후 생성 워크플로 드롭다운 목록에 대해 지원되는 버전, 출력 경로, SCORM 파일 이름(zip), 출력 템플릿 및 사후 생성 워크플로와 같은 기본 출력 설정을 지정하는 데 사용됩니다.

  ![](assets/scorm-general-tab-v3.png){width="650"}


- **콘텐츠:** 사용 가능한 조건부 필터링(DITAVAL 사용 또는 일부 조건 사전 설정 사용)과 변수 집합을 지정하는 데 사용합니다.

  ![](assets/scorm-content-tab.png){width="650"}

- **학습자 경험:** **학습자 경험** 탭을 사용하여 학습자가 SCORM 출력과 상호 작용하고 탐색하는 방법을 구성할 수 있습니다. 설정이 **일반**, **탐색** 및 **퀴즈**&#x200B;에 구성되어 있으므로 맞춤화된 학습 환경을 위해 콘텐츠 접근성, 탐색 흐름 및 퀴즈 동작을 제어할 수 있습니다.

  ![](assets/learner-experience.png){width="650"}

  - **일반:** 학습자용 PDF 다운로드 활성화와 같은 출력 수준 옵션을 구성합니다.

    - **학습자가 강의 PDF을 다운로드하도록 허용**: 활성화되면 이 옵션은 SCORM 출력에 PDF 아이콘을 추가합니다. 이 아이콘을 클릭하면 학습자가 게시된 출력에서 직접 강의 PDF 버전을 다운로드할 수 있습니다.

      **필수 구성 요소:** 이 옵션을 활성화하기 전에 다음을 확인하십시오.

      - **출력 템플릿**&#x200B;은(는) 원하는 위치에 **PDF 포함** 아이콘으로 구성해야 하며, SCORM 사전 설정을 구성하는 동안 **일반** 탭의 **출력 템플릿** 옵션에서 동일한 템플릿을 선택해야 합니다.

        ![](assets/embed-pdf.png){width="650"}

      - 관련된 **기본 PDF 사전 설정**&#x200B;을(를) 한 번 이상 생성해야 합니다. 생성되지 않은 PDF 사전 설정을 선택하면 사전 설정을 게시하라는 오류 메시지가 표시됩니다.

    위의 설정으로 SCORM 출력이 생성되면 결과 출력에는 아래와 같이 PDF 아이콘이 포함되어 학습자가 PDF 과정을 다운로드할 수 있습니다.

    ![](assets/pdf-icon.png){width="650"}

  - **탐색:** 순차적 진행률, 필수 완료 조건 및 **다음** 단추를 잠금 해제하는 규칙을 포함하여 학습자가 과정을 이동하는 방법을 정의합니다.

    - **학습자는 순차적 순서로 내용을 진행해야 합니다**: 학습자가 과정을 고정된 순서로 진행하도록 하며 과정 구성 요소 사이를 건너뛰거나 이동할 수 없습니다.
    - **학습자가 퀴즈에 실패하면 다음 단추를 사용하지 않도록 설정**: 학습자가 퀴즈를 통과할 때까지 다음 섹션/페이지로 이동할 수 없도록 차단합니다.
    - **학습자가 모든 질문을 시도하여 계속 진행해야 함**: 학습자가 퀴즈를 제출하기 전에 모든 질문을 시도하여 불완전한 제출을 방지해야 합니다.
    - **완료될 때까지 진행률 잠금**: 과정에서 **다음** 단추를 사용하지 않도록 설정하여 아래에 구성된 모든 하위 조건이 충족될 때까지 과정을 탐색하지 못하도록 합니다.
      - **모든 대화형 요소가 열림**: 학습자가 페이지의 모든 대화형 요소를 열어야 합니다.
      - **시청한 모든 미디어**: 학습자가 페이지의 모든 비디오/오디오 미디어를 시청해야 합니다.
      - **모든 지식 확인 시도**: 학습자가 페이지에서 모든 지식 확인 질문을 시도해야 합니다.
      - **페이지에서 보낸 최소 시간**: [다음] 단추를 사용하려면 학습자가 지정된 기간 이상 페이지에 머물러야 합니다. 활성화한 후에는 아래에 언급된 대로 필요한 시간을 입력해야 합니다.
        - **필요한 시간(초)**: 이 조건이 충족되기 위해 학습자가 페이지에 남아 있어야 하는 최소 시간(초)(예: `30`)입니다.

  - **퀴즈:** 질문 순서 및 답변 선택 무작위 지정과 같은 퀴즈 관련 동작을 구성하여 여러 시도에 대한 예측 가능성을 줄이십시오.

    - **각 시도에 대해 질문 순서 무작위 지정**: 모든 시도에 대해 다른 순서로 퀴즈 질문을 표시하여 예측 가능성을 줄이는 데 도움이 됩니다.
    - **각 시도에 대한 답변 선택 사항을 무작위로 지정**: 각 시도에 대한 답변 옵션을 섞어 추측 가능성을 줄입니다.

- **LMS에 게시:** 이 설정을 사용하여 콘텐츠를 ALM(Adobe Learning Manager)에 직접 게시합니다. **게시 서버** 드롭다운에서 **Adobe Learning Manager**&#x200B;을(를) 선택한 다음 이전에 Workspace 설정에 구성된 필수 **게시 프로필**&#x200B;을(를) 선택합니다. 선택한 프로필을 사용하여 연결을 설정하고 생성된 콘텐츠를 ALM에 업로드합니다.

  >[!NOTE]
  >
  > 콘텐츠를 ALM에 게시하기 전에 Adobe Learning Manager 게시 프로필을 구성해야 합니다. 자세한 내용은 [프로필 게시](../lc-config-guide/lc-folder-profile.md)를 참조하세요.

  ![](assets/scorm-publish-lms.png){width="650"}

모든 변경 사항이 구성되면 SCORM 사전 설정 페이지의 도구 모음 오른쪽 모서리에 있는 **저장**&#x200B;을 사용하여 SCORM 사전 설정에 대한 변경 사항을 저장합니다.
