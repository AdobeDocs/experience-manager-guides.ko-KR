# 상태 검사 사전 설정 만들기 및 관리

>[!NOTE]
>
> 이 기능은 기본적으로 활성화되어 있습니다. 사용자 환경에서 이 기능을 사용하지 않으려면 고객 지원 팀에 문의하십시오.

관리자는 작성자 및 게시자가 DITA 맵에서 상태 검사를 실행할 수 있도록 Experience Manager의 폴더 프로필 수준에서 상태 검사 기능을 구성할 수 있습니다. 여기에는 각 파일을 개별적으로 확인하는 대신 게시하기 전에 맵에서 끊어진 링크, 중복 ID 및 스키마 유효성 검사 실패와 같은 문제를 조기에 감지하는 것이 포함됩니다. 실행되는 검사는 작성자와 게시자가 선택하고 실행할 수 있는 규칙 세트인 상태 검사 사전 설정으로 정의됩니다.

이 문서에서는 상태 검사 사전 설정 만들기 및 관리에 대한 정보를 제공합니다.

## 상태 확인 사전 설정 만들기

폴더 프로필 수준에서 상태 확인 사전 설정을 만들려면 다음 단계를 수행하십시오.

1. [Workspace 설정](./workspace-settings.md)(으)로 이동한 다음 목록에서 **상태 확인**&#x200B;을 선택합니다.
1. **상태 검사 사전 설정** 패널에서 **새로 만들기**&#x200B;를 선택합니다.

   ![](./assets/health-check-preset-create.png)
1. **새 상태 검사 사전 설정** 대화 상자가 표시됩니다. 사전 설정 이름을 추가하고 포함할 규칙 또는 검사를 선택합니다. 사용 가능한 옵션은 끊어진 링크, 중복 ID 및 Schematron 유효성 검사입니다.

   ![](./assets/health-check-preset-dialog.png)
1. **만들기**&#x200B;를 선택합니다.
1. 설정을 저장하려면 **저장**&#x200B;을 선택하세요.

이제 작성자 및 게시자가 이 사전 설정을 사용할 수 있습니다. 작성자의 경우, 이 기능은 맵 보기에서 맵의 옵션 메뉴에서, 검색 패널과 함께 [상태 확인 보고서] 패널에서 사용할 수 있으며, 작성자는 프로필에 대해 구성된 상태 확인 사전 설정 중 하나를 사용하여 선택한 맵에서 상태 확인을 실행할 수 있습니다. 자세한 내용은 [맵 편집기의 추가 기능](../user-guide/map-editor-other-features.md#run-health-check-on-a-map)을 참조하세요.

게시자의 경우 **출력 생성 전 상태 검사 실행** 토글이 사전 설정 패널에 표시되며, 이 토글을 사용하여 요구 사항에 따라 활성화하거나 비활성화할 수 있습니다. 활성화되면 상태 확인 보고서는 게시 프로세스 시작 시 로그에 추가되지만 출력 생성을 차단하지 않습니다.

## 상태 검사 사전 설정 관리

사전 설정이 만들어지면 사전 설정에서 편집, 복제 또는 제거 작업을 수행할 수 있는 [상태 검사 사전 설정] 패널에 사전 설정이 추가됩니다.

![](./assets/health-check-preset-manage.png)

- **편집**: 사전 설정 이름, 확인(선택 또는 선택 해제), 사전 설정에 첨부된 Schematron 파일을 추가하거나 제거하는 등의 사전 설정 필드를 편집할 수 있습니다.
- **복제**: 같은 목록에 사전 설정의 중복을 만듭니다.
- **제거**: 패널에서 사전 설정을 제거합니다.

변경 내용을 저장하려면 **저장**&#x200B;을 선택하세요.
